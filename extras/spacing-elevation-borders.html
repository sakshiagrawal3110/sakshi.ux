Spacing system

Every spacing value across components and typography is a multiple of 4px, so any layout built from the system falls into the same rhythm without extra decisions.

OVERVIEW

In order to have consistency and a similar rhythm across page layouts, and to create harmonious arrangements of components and text, all spacing numbers are multiples of 4 — so every layout feels intentional and well designed.

SPACING SYSTEM

All spacing for components and typography is done in increments of 2px & 4px.
