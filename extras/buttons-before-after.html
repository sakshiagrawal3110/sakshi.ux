Primary button (Filled)

Purpose

  • Use for the main action on a page or module.
  • Should be the most visually prominent CTA.
  • Only 1 primary CTA per screen is recommended.

✓ Use cases

  • Hero banners
  • Submitting a form
  • Any action the user should immediately take

✕ Do not use

  • Less important tasks
  • Multiple times in a page
