# Handover Document

## 1. Project / Goal Overview
- **Goal:** The user, Sakshi, is building a highly polished, responsive, and interactive UX Designer portfolio website. 
- **Objectives:** The portfolio relies on a "bento-box" masonry grid layout. The primary objective is to achieve a premium, dynamic, and fluid "Framer-style" aesthetic. 
- **Success Criteria:** A flawlessly interlocking masonry grid with absolutely no empty gaps, perfectly flush bottom alignment, unified hover states, and smooth, springy (physics-based) animations. The portfolio includes a main index page and several highly detailed, interactive case study pages.

## 2. Context & Background
- **Situation:** The user has been iteratively refining the portfolio from a rigid square grid into a dynamic, flowing layout. 
- **Technologies:** Pure HTML, CSS, and vanilla JavaScript. 
- **Key Mechanics:** The main grid utilizes CSS Grid (`grid-auto-flow: dense`) with specific row/column spanning to create the masonry effect. Case studies embed interactive prototypes using `<iframe>` tags.
- **External Factors:** The user provides video references and screenshots of desired layouts and animations, requiring the AI to match the visual fidelity precisely.

## 3. Decisions Made
- **Consolidated Code:** Deprecated the external `styles.css` file. All CSS and JavaScript are now embedded directly within the HTML files for self-containment.
- **Grid Mathematics:** Recalculated the CSS grid using a 120px base row height with `row-span` increments to ensure all columns end perfectly flush at the bottom without any empty spaces.
- **Unified Interactions:** Standardized a circular diagonal hover arrow (`↗`) across all clickable tiles. Implemented a tactile "squish" (`transform: scale(0.96)`) on `:active` states for all tiles.
- **Iframe Handling:** Configured case study iframes to use `overflow: hidden` on wrappers and `width: 100%; height: 100%` to dynamically fit containers, eliminating ugly double vertical scrollbars and removing horizontal scrollbars entirely.
- **Tile Replacements:** Removed placeholder tiles (like "Fintech Redesign", "Duolingo", "Side Quests") and replaced them with fully fleshed-out, edge-to-edge animated tiles for specific case studies, a Resume download tile, a Gmail tile, a LinkedIn tile, and a Location (Mumbai) tile.
