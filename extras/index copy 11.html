Design Principles

Design systems improve efficiency and consistency, but never at the cost of user experience.

I treat design systems as living foundations, not rigid constraints. If breaking a pattern means solving a real user problem more effectively, I'll break it. Then I feed what I've learned back into the system so it evolves. The best design systems aren't the ones that enforce the most rules, but the ones that make it easier to do the right thing for users.
